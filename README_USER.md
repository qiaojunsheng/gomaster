# GoMaster Pro - 围棋助手使用说明

## 🎯 产品简介

GoMaster Pro 是一款专业的围棋AI分析助手，基于 KataGo 引擎，为您提供实时的围棋对弈分析和建议。

## 🚀 快速开始

### 1. 启动服务端

在终端中运行：
```bash
cd server
bash start_server.sh
```

等待看到 "KataGo 已就绪" 的提示，表示服务端启动成功。

### 2. 启动客户端

在另一个终端中运行：
```bash
cd client
bash start_client.sh
```

### 3. 首次配置

1. 点击客户端右上角的 **⚙️** 设置按钮
2. 选择您常用的平台（OGS/腾讯/野狐/弈城）
3. 点击 **保存设置**
4. 开始使用！

## ⚙️ 配置详解

### 平台预设

支持以下围棋平台：

- **OGS** - Online Go Server (online-go.com)
- **腾讯** - 腾讯围棋 (腾讯野狐)
- **野狐** - 野狐围棋
- **弈城** - 弈城围棋

### 棋盘区域

定义游戏棋盘的屏幕位置：
- **X, Y** - 棋盘左上角的屏幕坐标
- **宽, 高** - 棋盘的宽度和高度（像素）

### 监控区域

用于识别当前手数的屏幕区域：
- 通常是显示 "第X手" 或 "Move X" 的区域
- 用于判断轮到谁下棋

### GBR参数文件

棋盘识别参数文件，不同平台可能需要不同的参数：
- 位于 `screenshots/` 目录下
- 格式为 `.gpar` 文件

## 💡 使用技巧

### 在线对弈流程

1. **开始游戏前**：
   - 确认选择了正确的平台
   - 确认选择了正确的执子颜色
   - 确认棋盘区域配置正确

2. **游戏中**：
   - 开启 **轮巡** 模式自动分析
   - 或手动点击 **下一步** 获取建议
   - 查看可视化棋盘了解推荐点

3. **打劫处理**：
   - 系统会自动检测打劫
   - 会推荐第二选点避免违规

### 快捷键

- 点击 **?** 按钮查看帮助
- 点击 **⚙️** 按钮打开配置
- 状态指示灯：
  - 🟢 绿色 = 已连接
  - 🔴 红色 = 未连接
  - 🟡 黄色 = 连接中

## 🔧 故障排除

### 常见问题

#### 1. 连接失败（状态红色）

**原因**：服务端未启动或网络问题

**解决**：
```bash
# 检查服务端是否运行
cd server
bash start_server.sh
```

#### 2. 棋盘识别失败

**原因**：棋盘区域配置不正确

**解决**：
1. 打开配置界面
2. 重新选择平台预设
3. 或手动调整棋盘区域坐标

#### 3. 落子位置不准

**原因**：GBR参数文件不匹配

**解决**：
- 尝试切换不同的 `.gpar` 参数文件
- 或使用平台预设自动配置

#### 4. 监控文字识别失败

**原因**：监控区域配置不正确

**解决**：
- 调整监控区域到显示手数的位置
- 确保该区域能清晰显示当前手数

### 系统要求

- **操作系统**: macOS / Linux / Windows
- **Python**: 3.8 或更高版本
- **内存**: 建议 8GB 以上
- **显卡**: 支持 Metal (macOS) 或 CUDA (NVIDIA)
